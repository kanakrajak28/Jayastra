# Jayastra website

Live at https://www.jayastra.com, deployed by Vercel from this repo.

## Folders
- `Jayastra/`: the built website that Vercel serves (Vercel's Root Directory is set to `Jayastra`). Don't edit it by hand; it's regenerated by the build.
- `source/src/`: page content and components (React + Framer Motion), one file per section (see below).
- `source/src/shell.html`: all CSS and the HTML shell.
- `source/site/img/`: photos; `source/site/logo*.png`: logos.
- `source/brand/`: favicons and the social share image.
- `source/build.py`: builds `Jayastra/` (one pre-rendered page per URL, sitemap, robots, vercel.json).

## Where things are in `source/src/`
| File | What it is |
| --- | --- |
| `main.jsx` | Entry point: mounts `<App />` |
| `App.jsx` | Routing (home, sector, case, work, legal, 404), page titles, smooth scroll, page layout order |
| `lib/react.js` | React hooks (`useState`, `useEffect`, ...) taken from the React global |
| `lib/utils.js` | Image helpers (`img`, `imgHi`, Unsplash IDs), routing link helper `to()`, easing, media queries |
| `lib/motion.js` | Framer Motion, with a static fallback if it fails to load |
| `components/shared.jsx` | Small shared pieces: `Arrow`, `Reveal`, `SectionHead`, `MagLink`, `EyeButton` |
| `components/Preloader.jsx` | "Hello" intro screen |
| `components/Header.jsx` | Top navigation (`NAV` links) |
| `components/Hero.jsx` | Hero headline and WebGL light |
| `components/Statement.jsx` | Marquee and the studio statement |
| `components/Work.jsx` | Work section: the page-turning photo album |
| `components/Services.jsx` | Services grid (`DISCIPLINES`) |
| `components/Industries.jsx` | Industries list (`INDUSTRIES`, `SECTOR_SLUGS`) |
| `components/CaseStudies.jsx` | Case study data (`CASES`, `FEATURED`) and the home-page case studies section |
| `components/Process.jsx` | Process timeline (`STEPS`) |
| `components/Mark3D.jsx` | 3D spear from the logo |
| `components/Stats.jsx` | Stats counters (`STATS`) |
| `components/Advantage.jsx` | "The Jayastra advantage" cards |
| `components/Testimonials.jsx` | Testimonials and dot globe |
| `components/Pricing.jsx` | Pricing cards |
| `components/FAQ.jsx` | FAQ (`FAQS`) |
| `components/GlyphMark.jsx` | Logo drawn in glyphs |
| `components/Contact.jsx` | Contact section (tile background, layout) |
| `components/Booker.jsx` | The booking / enquiry form (sends by email) |
| `components/Footer.jsx` | Footer, big wordmark, clock |
| `pages/SectorPage.jsx`, `CasePage.jsx`, `WorkIndex.jsx`, `NotFound.jsx`, `Legal.jsx` | Inner pages; `PageShell.jsx` wraps them |

`build.py` bundles everything from `main.jsx` with esbuild, and reads the industry, case-study and image data from these files to make the per-page titles and the sitemap. Keep those data arrays in the same format.

## Make a change
1. Edit the file for that section in `source/src/`, or `source/src/shell.html` for CSS.
2. Build: `cd source && python build.py` (needs Python 3 and Node.js; esbuild is fetched automatically with npx).
3. Commit and push: `git add -A && git commit -m "Describe the change" && git push`.
Vercel redeploys jayastra.com within a minute or two.

`source/site/index.html` is a single-file preview you can open locally after building.
