# Jayastra website

Live at https://www.jayastra.com, deployed by Vercel from this repo.

## Folders
- `Jayastra/`: the built website that Vercel serves (Vercel's Root Directory is set to `Jayastra`). Don't edit it by hand; it's regenerated by the build.
- `source/src/`: page content and components (React + Framer Motion), one file per section (see below).
- `source/src/shell.html`: all CSS and the HTML shell.
- `source/site/img/`: photos; `source/site/logo*.png`: logos.
- `source/brand/`: favicons and the social share image.
- `source/build.py`: builds `Jayastra/` (one pre-rendered page per URL, sitemap, robots, vercel.json).
- `source/prerender.js` + `source/ssr-entry.jsx`: used by the build to render each page with React in Node, so every page's HTML contains its text (for Google and AI crawlers, which often don't run JavaScript). The build also writes the structured data (JSON-LD) and `llms.txt` from the same data. `source/.cache/` holds downloaded copies of React and Framer Motion for this; it's not committed.

`build.py` bundles everything from `main.jsx` with esbuild, and reads the industry, case-study and image data from these files to make the per-page titles and the sitemap. Keep those data arrays in the same format.

## Make a change
1. Edit the file for that section in `source/src/`, or `source/src/shell.html` for CSS.
2. Format (optional): `cd source && npx prettier --write src` keeps the code style consistent (settings in `source/.prettierrc`; for `shell.html` only the CSS is formatted).
3. Build: `cd source && python build.py` (needs Python 3 and Node.js; esbuild is fetched automatically with npx).
4. Commit and push: `git add -A && git commit -m "Describe the change" && git push`.
Vercel redeploys jayastra.com within a minute or two.

`source/site/index.html` is a single-file preview you can open locally after building.
